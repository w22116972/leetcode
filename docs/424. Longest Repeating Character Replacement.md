# [424. Longest Repeating Character Replacement](https://leetcode.com/problems/longest-repeating-character-replacement/)

## Problem scope

- Is `s` non-empty string?
- Is `k` is a positive integer?
- The length of `s` is at most 10^5.
- The string contains only uppercase English letters.
- `0 <= k <= s.length` ?

## Algorithm

Least replacement is to replace all characters except the most frequent character.
1. Use a sliding windows to keep track of substring and the count of the most frequent character.
2. If the number of replacement (the length of substring minus the count of the most frequent character) is greater than `k`, find the next substring by moving the left pointer.
3. No need to update `mostFrequentCount` when window shrinks because shorter `mostFrequentCount` won't find longer length

```java
public int characterReplacement(String s, int k) {
    int[] frequentCount = new int[26];
    int mostFrequentCount = 0;
    int maxSubstringLength = 0;
    int left = 0;
    while (right < s.length()) {
        frequentCount[s.charAt(right) - 'A']++;
        mostFrequentCount = Math.max(mostFrequentCount, frequentCount[s.charAt(right) - 'A']);
        if (right - left + 1 - mostFrequentCount > k) {
            frequentCount[s.charAt(left) - 'A']--;
            left++;
        }
        maxSubstringLength = Math.max(maxSubstringLength, right - left + 1);
        right++;
    }
    return maxSubstringLength;
}
```

## Complexity analysis

- T(n) = O(n)
- S(n) = O(1)
  - `int[26]`
    - size = 26
    - each `int` in java is 4 bytes
    - 26 * 4 = 104 bytes

## Test cases

- Test empty string `s`
  - Input: `s = "", k = 2`
  - Output: `0`
- Test Single Character with No Replacements
  - Input: `s = "A", k = 0`
  - Output: `1`
- Test `k` is greater than the length of `s`
  - Input: `s = "AB", k = 3`
  - Output: `2`
- Test consecutive replacements
  - Input: `s = "ABABAB", k = 2`
  - Output: `5`
- Test normal case
  - Input: `s = "ABAB", k = 2`
  - Output: `4`
- Test all characters are the same
  - Input: `s = "AAAA", k = 2`
  - Output: `4`
- Test all characters are different
  - Input: `s = "ABCD", k = 2`
  - Output: `3`
- Test the length of substring is less than `k`
  - Input: `s = "A", k = 2`
  - Output: `1`
- Test the length of substring is equal to `k`
  - Input: `s = "AB", k = 1`
  - Output: `2`
- Test the length of substring is greater than `k`
  - Input: `s = "AB", k = 0`
  - Output: `1`
