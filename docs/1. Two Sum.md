# [Two Sum](https://leetcode.com/problems/two-sum/)

## 1. Clarify the problem and collect constraints

- Does the array contain at least two elements?
- Is `len(nums)` <= 10^4?
- Does the number in `nums` fit in a 32-bit signed integer?
- Are `nums` are all integers?
- Are there any duplicates in `nums`?
- Are `nums` sorted?
- Do many answers exist?
- What should return if no answer exists?
- Can we modify the input array?

## 2. Design Algorithm and Time/Space Complexity

### Two Pointers

I see that this problem might be simplified if the array is sorted. Once sorted, I can use a two-pointer technique: one pointer at the start (left) and one at the end (right). Then, I’ll adjust the pointers inward based on whether the sum is too large or too small.

Sorting the array allows us to leverage the fact that the sum of a smaller element plus a larger element either increases or decreases predictably as we move the pointers. That way, we can find a matching pair in a single pass

```java
public int[] twoSum(int[] nums, int target) {
    // To avoid modifying the input array
    int[] sortedNums = nums.clone();
    // First, we need to sort the array
    Arrays.sort(sortedNums);
    // Declare two pointers
    int left = 0;
    int right = sortedNums.length - 1;
    
    // Use hashMaps to store the indices of the numbers
    HashMap<Integer, List<Integer>> indexMap = new HashMap<>();
    for (int i = 0; i < nums.length; i++) {
        if (!indexMap.containsKey(nums[i])) {
            indexMap.put(nums[i], List.of(i));
        } else {
            List<Integer> indices = indexMap.get(nums[i]);
            indices.add(i);
            indexMap.put(nums[i], indices);
        }
    }
    
    while (left < right) {
        int sum = sortedNums[left] + sortedNums[right];
        if (sum == target) {
            // Get the indices of the two numbers
            int leftIndex = indexMap.get(sortedNums[left]).get(0);
            int rightIndex = indexMap.get(sortedNums[right]).get(0);
            // If the two numbers are the same, get the second index from the list
            if (sortedNums[left] == sortedNums[right]) {
                rightIndex = indexMap.get(sortedNums[right]).get(1);
            }
            return new int[]{leftIndex, rightIndex};
        } else if (sum < target) {
            left++;
        } else {
            right--;
        }

    }
    return new int[0];
}
```

Time/Space Complexity
- T = `O(NlogN)` to sort the array
- S = `O(N)` to store the indices of the numbers

### Hash Map stores the difference between the target and the current element

```java
public int[] twoSum2(int[] nums, int target) {
    HashMap<Integer, Integer> map = new HashMap<>();
    for (int i = 0; i < nums.length; i++) {
        // Check if the current element exists in the HashMap
        if (map.containsKey(nums[i])) {
            return new int[]{map.get(nums[i]), i};
        }
        // Store the difference between the target and the current element
        map.put(target - nums[i], i);
    }
    return new int[0];
}
```

Time/Space Complexity
- T = `O(N)` to iterate through the array
- S = `O(N)` to store the difference between the target and the current element
