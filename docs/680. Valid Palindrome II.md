# 680. Valid Palindrome II

> https://leetcode.com/problems/valid-palindrome-ii/description/

Consider deleting at most one character, it leads to a choice of two options:
- Delete the character at the left pointer.
- Delete the character at the right pointer.

Use recursion to check if the substring is a palindrome after deleting one character.

```java
    public boolean validPalindrome(String s) {
        int i = 0;
        int j = s.length() - 1;
        while (i < j) {
            if (s.charAt(i) != s.charAt(j)) {
                return isValidPalindrome(s, i + 1, j) || isValidPalindrome(s, i, j - 1);
            }
            i++;
            j--;
        }
        return true;
    }

    private boolean isValidPalindrome(String s, int left, int right) {
        while (left < right) {
            if (s.charAt(left) != s.charAt(right)) {
                return false;
            } else {
                left++;
                right--;
            }
        }
        return true;
    }
```
