# [15. 3Sum](https://leetcode.com/problems/3sum/)

## 1. Clarify the problem and constraints

- Are there at least three elements in the array?
- Are the elements in the array integers?
- Are there any duplicates in the array?
- Are the elements sorted?
- Can we modify the input array?
- Are there multiple answers?
- What should return if no answer exists?
- Are the elements in the array within the range of 10^5?
- Are the elements in the array within the range of -10^5?

## 2. Design Algorithm and Time/Space Complexity

For `a + b + c = 0`, we can find `a, b s.t a + b = -c` . This problem can be solved using a two-pointer technique.

We need to handle duplicates to avoid duplicate triplets in the result.
- If `c` is duplicate
- If `a` is duplicate
- We don't need to handle `b` because `[a, c]` is unique after the above handling, the result `b = -c - a` will be unique as well.

After sorting, if `c` is positive, we can skip the rest of the array because the `b + c` will always be positive (`> -c`).

### Two Pointers

```java
import java.util.ArrayList;
import java.util.List;

public List<List<Integer>> threeSum(int[] nums) {
    // First, we need to sort the array
    List<Integer> sortedNums = new ArrayList<>(nums.length);
    for (int i = 0; i < nums; i++) {
        sortedNums.add(nums[i]);
    }
    sortedNums.sort();
    

    List<List<Integer>> result = new ArrayList<>();

    for (int i = 0; i < sortedNums.length - 2; i++) {
        // We treat the current number `sortedNums[i]` as the target value s.t. sortedNums[left] + sortedNums[right] =? -sortedNums[i] 

        // After sorting, if `c` is positive, we can skip the rest of the array because the `b + c` will always be positive (`> -c`).
        if (sortedNums[i] > 0) {
            break;
        }

        // If the target value is the same as previous, skip to avoid duplicates
        if (i > 0 && sortedNums[i] == sortedNums[i - 1]) {
            continue;
        }

        List<List<Integer>> pairs = findAllPairsSumToTargetOnSortedArray(sortedNums, i + 1, -sortedNums[i]);
        for (List<Integer> pair : pairs) {
            result.add(List.of(sortedNums[i], pair.get(0), pair.get(1)));
        }
    }
    return result;
}

public List<List<Integer>> findAllPairsSumToTargetOnSortedArray(List<Integer> sortedNums, int startIndex, int target) {
    List<List<Integer>> result = new ArrayList<>();
    int leftIndex = startIndex;
    int rightIndex = sortedNums.size() - 1;
    while (leftIndex < rightIndex) {
        int sum = sortedNums.get(leftIndex) + sortedNums.get(rightIndex);
        if (sum == target) {
            result.add(List.of(sortedNums.get(leftIndex), sortedNums.get(rightIndex)));
            leftIndex++;
            // If left is duplicate to the previous value, skip to avoid duplicates
            while (leftIndex < rightIndex && sortedNums.get(leftIndex) == sortedNums.get(leftIndex - 1)) {
                leftIndex++;
            }
        } else if (sum < target) {
            leftIndex++;
        } else {
            rightIndex--;
        }
    }

    return result;
}
```

Time/Space Complexity:
- `T(n) = O(n^2)` because we iterate through the array and for each element, we find pairs that sum to the target.
- `S(n) = O(n)` because we store the sorted array. If considering the space for the result, `S(n) = O(n^2)`.
