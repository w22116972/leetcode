# [11. Container With Most Water](https://leetcode.com/problems/container-with-most-water/)

## Problem scope

- Is an integer array?

## Algorithm

Area is equal to the width (difference between index of left and right pointers) times with the height (minimum value between left and right pointers of height).

1. Initialize two pointers, left and right, at the beginning and end of the array.
2. Calculate the area.
3. Move the pointer with the smaller height. (Try to find a larger height.)
   - No need to consider the equal height 
4. Update the maximum area.
